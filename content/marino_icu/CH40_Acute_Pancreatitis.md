## Chapter 40: Acute Pancreatitis

> "Medicine cures the man who is fated not to die."
> — Chinese Proverb

急性胰臟炎（Acute pancreatitis）是需要住院治療的主要腹部疾病之一（1），但大多數病例並不嚴重到需要入住 ICU。然而，需要入住 ICU 的病例往往（或很快變得）是 ICU 中病情最危重的患者。

本章描述急性胰臟炎的臨床特徵和管理，特別強調需要 ICU 照護的嚴重病例。嚴重胰臟炎的處理具有挑戰性，因為**沒有特定的治療方法**（除了去除任何致病因素），而且整體死亡率（約 **25%**）在過去二十年中沒有改變（2）。

## 導讀摘要

- **急性胰臟炎**主因為**膽結石**（21–33%）與**酒精**（16–27%）；約 75% 病例由此二因素或不明原因所致
- **高三酸甘油酯血症**（hypertriglyceridemia）已成為急性胰臟炎的重要病因，當血清三酸甘油酯 > **1,000 mg/dL** 時可能引發胰臟炎，且症狀通常較嚴重
- 急性胰臟炎分為**水腫性**（占約 80%，多為輕症自限）與**壞死性**（占約 20%，嚴重且死亡率高）
- 胰臟外分泌細胞受損會釋放消化酶，**胰蛋白酶**（trypsin）進一步促進自體消化與全身性發炎反應，導致多重器官衰竭
- 急性胰臟炎的 ICU 處理重點在於**積極輸液復甦**、**疼痛控制**、**營養支持**（儘早開始腸道營養）以及**移除致病因素**

**表｜急性胰臟炎重要數值**

| 臨床數值 | 說明 |
|---|---|
| 膽結石占病因比例 | 21–33% |
| 酒精占病因比例 | 16–27% |
| 不明原因占病因比例 | 10–15% |
| 高三酸甘油酯血症引發胰臟炎閾值 | > 1,000 mg/dL |
| 高三酸甘油酯血症占所有胰臟炎比例 | 2–7% |
| 水腫性胰臟炎占比 | ~80% |
| 壞死性胰臟炎占比 | ~20% |
| 嚴重急性胰臟炎整體死亡率 | ~25% |

## 病理生理學（Pathophysiology）

### 解剖學與生理學

胰臟包含兩種類型的細胞：

- **「蘭氏小島」細胞（Islet cells）**——具有**內分泌功能**，分泌 insulin、glucagon 與 somatostatin
- **「腺泡」細胞（Acinar cells）**——具有**外分泌功能**，分泌消化酶如 amylase、lipase 與 trypsin

### 疾病機制

急性胰臟炎是一種主要影響**腺泡（外分泌）細胞**的發炎過程。這些細胞的破壞會釋放消化酶，而像 **trypsin** 這樣的蛋白水解酶會加重胰臟損傷並促進胰臟的「自體消化」（autodigestion）。胰臟損傷會觸發**全身性發炎反應**（systemic inflammatory response syndrome, SIRS），這可能導致其他器官的發炎性損傷，最終導致**多重器官衰竭**（multi-organ failure, MOF）。

## 病因學（Etiologies）

**表 40.1｜急性胰臟炎的病因**

| 較常見† | 較少見 |
|---|---|
| 膽結石（Gallstones）（21–33%） | 酒精（Alcohol）（16–27%） |
| 不明原因（Idiopathic）（10–15%） | 高三酸甘油酯血症（Hypertriglyceridemia）（2–7%） |
| 藥物（Drugs）（3–4%） | 高血鈣（Hypercalcemia） |
| | 腹部創傷（Abdominal trauma） |
| | 感染（Infections） |
| | 血管炎（Vasculitis） |

> †括號中為報告的盛行率。

約四分之三的病例是**膽結石**、**酒精濫用**或**不明原因**所導致（1,3），其他值得注意的原因包括**高三酸甘油酯血症**（4,5）、**藥物**（6）與**感染**（7）。

### 高三酸甘油酯血症（Hypertriglyceridemia）

嚴重的高三酸甘油酯血症（血清三酸甘油酯 > **1,000 mg/dL**）是高達 **7%** 急性胰臟炎症例的原因（4），近年來病例頻率大幅增加（5）。可能涉及多種機制，但其中一個主要機制是從三酸甘油酯釋放**多不飽和脂肪酸**（polyunsaturated fatty acids, PUFAs），因為 PUFAs 高度易於氧化並能夠引發發炎反應。

由高三酸甘油酯血症引起的胰臟炎比其他類型的胰臟炎**更嚴重**，並伴隨更高程度的全身性發炎與胰臟外器官損傷（4）。幸運的是，有一種有效的治療方法，將在本章後面描述。

### 藥物相關胰臟炎（Drug-Induced Pancreatitis）

已報告可引起胰臟炎的藥物包括：

- **Azathioprine**
- **Didanosine**
- **Diuretics**（thiazides、furosemide）
- **Valproic acid**
- **Corticosteroids**

## 分類（Classification）

**表 40.2｜急性胰臟炎的分類**

| 特徵 | 水腫性胰臟炎（Edematous） | 壞死性胰臟炎（Necrotizing） |
|---|---|---|
| **盛行率** | 約 80% 的病例 | 約 20% 的病例 |
| **嚴重程度** | 通常輕微、自限性 | 嚴重，死亡率較高 |
| **區域併發症** | 胰周液體積聚 | 胰臟壞死、膿腫、假性囊腫 |
| **全身性發炎** | 中度 | 嚴重（SIRS、MOF） |

## 嚴重程度評估（Severity Assessment）

### Ranson 標準

**入院時評估（Ranson criteria at admission）：**

| 標準 | 數值 |
|---|---|
| 年齡 | >55 歲 |
| WBC | >16,000/mm³ |
| 血糖 | >200 mg/dL |
| LDH | >350 IU/L |
| AST | >250 IU/L |

**入院後 48 小時評估：**

| 標準 | 數值 |
|---|---|
| Hct 下降 | >10% |
| BUN 上升 | >5 mg/dL |
| 血鈣 | <8 mg/dL |
| PaO₂ | <60 mm Hg |
| Base deficit | >4 mEq/L |
| 估計液體隔離 | >6 L |

> 3 個或以上 Ranson 標準提示重症胰臟炎。

### APACHE II 分數

**APACHE II ≥8** 分也提示重症胰臟炎。

## ICU 管理（ICU Management）

### 積極輸液復甦（Aggressive Fluid Resuscitation）

這是急性胰臟炎初始管理的基石：

- 前 **24 小時**需要大量靜脈輸液（可達 **4–6 L/crystaloid**）
- 目標：**尿量 ≥0.5 mL/kg/hr**
- 使用**乳酸林格氏液**（Lactated Ringer's）優於生理鹽水
- 監測：**BUN**、**Hct**、**尿量**、**血氣分析**

> **重要：** 早期積極輸液復甦可降低胰臟壞死的風險。

### 疼痛控制（Pain Control）

- **靜脈嗎啡**或 **hydromorphone** 是首選
- 避免使用 **meperidine**（其代謝產物 normeperidine 積累可引起癲癇）
- 持續疼痛可能預示壞死性胰臟炎

### 營養支持（Nutritional Support）

- **輕症**：禁食 24–48 小時後可開始進食
- **重症**：**儘早開始腸道營養**（入院後 24–48 小時內）
  - 鼻胃管或鼻空腸管餵食
  - 腸道營養可維持腸道屏障功能，減少感染風險
- **腸道營養不可行時**：才考慮全靜脈營養（TPN）

### 高三酸甘油酯血症的治療

- **胰島素**：降低血清三酸甘油酯
- **血漿置換**（Plasmapheresis）：快速降低三酸甘油酯
- **目標**：三酸甘油酯 < **500 mg/dL**

### 抗生素使用

- **不建議常規預防性使用抗生素**
- 抗生素僅用於：證實的感染性壞死、胰周膿腫、膽道炎
- 可選藥物：**carbapenems**（如 meropenem）、**fluoroquinolones** + **metronidazole**

### 介入與手術治療

- **壞死性胰臟炎伴感染**：延遲干預（>4 週），首選**內視鏡或經皮引流**
- **無菌壞死**：保守治療，除非有症狀
- **膿腫**：經皮引流或手術引流

## 局部併發症（Local Complications）

**表 40.3｜急性胰臟炎的局部併發症**

| 併發症 | 說明 |
|---|---|
| **急性胰周液體積聚**（Acute peripancreatic fluid collection） | 早期（<4 週）發生，無包膜 |
| **假性囊腫**（Pseudocyst） | 晚期（>4 週）發生，有包膜 |
| **急性壞死積聚**（Acute necrotic collection） | 壞死組織 + 液體，無包膜 |
| **包裹性壞死**（Walled-off necrosis, WON） | 晚期（>4 週），壞死組織有包膜 |
| **胰臟膿腫** | 壞死伴感染，需抗生素 ± 引流 |

---

## 系統性併發症（Systemic Complications）

急性胰臟炎可引發全身性發炎反應，導致：

- **肺臟**：ARDS、胸腔積液、低氧血症
- **腎臟**：急性腎損傷（AKI）
- **心血管**：低血壓、休克
- **血液系統**：DIC
- **代謝**：高血糖、低血鈣

> **預後標記：** 入住 ICU 的患者死亡風險最高的時期是疾病早期（前 2 週），主要由**多重器官衰竭**決定，而非感染的局部併發症。
