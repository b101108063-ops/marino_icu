## Chapter 45: Disorders of Consciousness

> "I think, therefore I am."
> — René Descartes (1644)

識別和與周圍環境互動的能力（意識）是生命體驗的絕對必要條件，而這種能力的喪失是危及生命的疾病的主要和令人恐懼的徵兆之一。本章描述 ICU 中遇到的主要意識障礙，特別強調**譫妄**（delirium）、**昏迷**（coma）和**腦死**（brain death）。

---

## 導讀摘要

- **意識障礙**的兩大要素：**覺醒**（arousal）與**覺知**（awareness）。狀態包括：**焦慮/嗜睡**（可喚醒+覺知正常）、**譫妄**（可喚醒+覺知障礙，波动性精神狀態）、**木僵/植物人/腦死**（不可喚醒）
- **譫妄**（Delirium）在 ICU 常見，風險因子包括**高齡**、**苯二氮平類**（benzodiazepines）、鎮靜、sleep deprivation；**CAM-ICU** 為標準篩檢工具；**Haloperidol**（2–5 mg IV）為首選藥物，**quetiapine**、**dexmedetomidine** 為替代
- **Glasgow Coma Scale（GCS）**：總分 3–15，**GCS ≤8** 定義為昏迷，亦為氣道保護反射缺陷的門檻；**瞳孔檢查**：針尖瞳孔見於**類鴉片過量**或**橋腦出血**；單側放大固定瞳孔提示 **CN III 壓迫**（腦疝）
- **酒精戒斷/譫妄性震顫**（delirium tremens）發生於停酒後 **72–96 小時**，特徵包括意識混亂、發燒、自律神經不穩；首選 **lorazepam** 或 **diazepam**；**thiamine**（100 mg）需在葡萄糖前給予以防 **Wernicke 腦病**
- **腦死判定**：需已知昏迷原因、排除混淆因素（低溫、藥物、電解質）、無所有腦幹反射、無對疼痛的運動反應、**apnea test** 陽性；確認性檢查（EEG、腦血管造影、核醫、TCD）可作為輔助

---

## 意識的兩個組成部分

Consciousness 有兩個組成部分：

1. **覺醒（Arousal）** — 體驗周圍環境的能力（覺醒狀態）
2. **覺知（Awareness）** — 理解自己與周圍環境關係的能力（反應能力）

**表 45.1｜意識改變狀態分類**

| | 可被喚醒 | 無法被喚醒 |
|---|---|---|
| **有覺知** | 焦慮、嗜睡 | — |
| **無覺知** | Delirium、痴呆、Locked-In 狀態 | 木僵、植物人狀態、昏迷、腦死 |

### 主要狀態的描述

1. **焦慮和嗜睡** — 覺醒和覺知完好，但專注力有變化。

2. **Locked-In 狀態** — 覺醒和覺知完好，但幾乎完全沒有運動反應。由於腦橋腹側運動路徑的雙側損傷，導致所有自主運動消失，除了上下眼球運動和眼瞼眨眼。

3. **Delirium 和痴呆** — 覺醒完好，但覺知改變。覺知的改變可以是波動性的（delirium）或永久性的（痴呆）。

4. **木僵（Stupor）** — 受試者難以喚醒，對環境中的某些或所有元素沒有覺知。

5. **植物人狀態（Vegetative state）** — 有一定程度的覺醒（眼睛可以睜開），但沒有覺知。可以存在自發運動和對深層疼痛的運動反應，但運動是無目的的。一個月後，這種情況稱為**持續性植物人狀態**（persistent vegetative state）。

6. **昏迷（Coma）** — 覺醒和覺知完全缺失（無法喚醒的無覺知）。可以存在自發運動和對深層疼痛的運動反應，但運動是無目的的。

7. **腦死（Brain death）** — 與昏迷相似，覺醒和覺知完全缺失。然而，腦死與昏迷有兩個不同之處：(a) 它涉及所有腦幹功能的喪失，包括顱神經反應和自發呼吸，(b) 它**總是不可逆的**。

## 譫妄（Delirium）

**Delirium** 是一種**急性注意力障礙和認知障礙**，在 ICU 中代表著**醫療急症**。它的特徵是：

- **波動性的精神狀態**
- **注意力障礙**（inattention）
- **思維紊亂**
- **意識水平改變**

### 風險因子（Risk Factors）

- **高齡**
- 既有認知障礙
- 嚴重疾病
- 鎮靜藥物（尤其是 **benzodiazepines**）
- **睡眠剝奪**（sleep deprivation）
- 約束
- **Mechanical ventilation**

### 臨床特徵（Clinical Features）

- **過動型 delirium（Hyperactive delirium）**：激動、躁動、幻覺、情緒不穩
- **低動型 delirium（Hypoactive delirium）**：嗜睡、反應降低、社交退縮（**在 ICU 患者中更常見**）
- **混合型 delirium（Mixed delirium）**：兩者的特徵

### 診斷（Diagnosis）

**ICU 混淆評估方法（CAM-ICU）** 是一種經過驗證的篩檢工具，用於篩檢機械通氣患者的 delirium。它評估以下四個特徵：

1. 精神狀態的急性改變或波動
2. 注意力障礙（inattention）
3. 思維紊亂
4. 意識水平改變

> **篩檢陽性：** 滿足特徵 1 + 2，並且滿足特徵 3 或 4 之一，即為 CAM-ICU 陽性。

### 預防與管理（Prevention and Management）

**非藥物措施（一線）：**

- 定向策略（定向力訓練）
- 正常化睡眠-覺醒週期
- **早期活動**
- 移除不必要的約束
- 糾正感覺缺陷（眼鏡、助聽器）
- 足夠的水分和營養

**藥物措施（用於構成安全風險的嚴重激動）：**

**表 45.2｜ICU 相關 Delirium 嚴重激動的藥物治療**

| 藥物 | 典型劑量 | 備註 |
|---|---|---|
| **Haloperidol** | 2–5 mg IV/IM；按需要重複 | 一線抗精神病藥物；需監測 **QTc** |
| **Quetiapine** | 25–50 mg PO，每日兩次 | 非典型抗精神病藥物；鎮靜較少 |
| **Dexmedetomidine** | 0.2–1.5 mcg/kg/hr IV | Alpha-2 激動劑；**保留呼吸驅動** |

> **注意：Benzodiazepines 通常應避免用於 delirium**（除了酒精/benzodiazepine 戒斷），因為它們可能使意識混亂惡化。

## 酒精戒斷與譫妄性震顫（Alcohol Withdrawal & Delirium Tremens）

### 臨床時間線

**表 45.3｜Alcohol 戒斷的臨床特徵**

| 時間線 | 特徵 |
|---|---|
| **6–24 小時** | 顫抖、焦慮、發汗、心搏過速、輕度高血壓 |
| **24–48 小時** | 幻覺（視覺、聽覺、觸覺） |
| **48–72 小時** | 戒斷癲癇（全身性強直-陣攣性） |
| **72–96 小時** | **Delirium tremens** — 意識混亂、激動、發燒、自律神經不穩、幻覺 |

### 治療原則

- **Benzodiazepines** 是主要治療（如 **lorazepam**、**diazepam**、**chlordiazepoxide**）。使用症狀觸發或固定日程給藥。
- **Beta-blockers**（如 propranolol、atenolol）可以減弱自律神經症狀，但不能預防癲癇。
- **Thiamine**（**100 mg** IV/PO，每日）應在葡萄糖之前給予以預防 **Wernicke 腦病**。
- 如果有低鎂血症，給予**鎂**補充。

## 昏迷（Coma）

### Glasgow Coma Scale（GCS）

**Glasgow Coma Scale（GCS）** 評估意識的三個組成部分：

**表 45.4｜Glasgow Coma Scale**

| 組成部分 | 反應 | 分數 |
|---|---|---|
| **睜眼（E）** | 自發性 | **4** |
| | 對言語 | **3** |
| | 對疼痛 | **2** |
| | 無 | **1** |
| **語言溝通（V）** | 定向力正常 | **5** |
| | 對話混亂 | **4** |
| | 不適當但可辨識的詞語 | **3** |
| | 無法理解的聲音 | **2** |
| | 無 | **1** |
| **運動反應（M）** | 服從命令 | **6** |
| | 對疼痛定位 | **5** |
| | 對疼痛逃避 | **4** |
| | 異常屈曲（去皮質反應） | **3** |
| | 異常伸展（去腦反應） | **2** |
| | 無 | **1** |

**總分範圍：** 3（最差）到 15（最好）

> **注意：** 對於氣管內插管患者，最高分是 **11**（語言 = 1）。

### GCS 的臨床應用

GCS 在癱瘓、深度鎮靜或低血壓的患者中**不可靠**。否則，GCS 可用於：

1. **定義昏迷**（**GCS ≤8**）
2. **分層頭部損傷的嚴重度**：輕度（GCS = 13–15）、中度（GCS = 9–12）、重度（GCS ≤8）
3. **識別插管的候選人** — 氣道保護反射通常在 **GCS ≤8** 時有缺陷
4. 作為**預後標記**

> **臨床要點：** GCS 是評估意識水平的基本工具，但必須結合瞳孔檢查和生命徵象綜合判斷。

## 瞳孔檢查（Pupillary Examination）

**表 45.5｜影響瞳孔大小和反應性的條件**

| 發現 | 可能原因 |
|---|---|
| **雙側放大、固定瞳孔** | Anticholinergic 毒性、嚴重缺氧、腦死、腦疝（晚期） |
| **單側放大、固定瞳孔** | **CN III 壓迫**（腦疝、顱內动脉瘤） |
| **小而又有反應的瞳孔** | 正常；opioid 使用；橋腦病灶 |
| **針尖瞳孔**（Pinpoint） | **Opioid 過量**（伴隨呼吸抑制）；**橋腦出血** |
| **單側放大、有反應** | CN III 麻痺（非腦疝原因） |
| **中等大小、固定** | 中腦病灶；深度鎮靜 |

> **緊急徵兆：** 單側放大固定瞳孔是**腦疝**的早期徵兆，需立即影像學評估和緊急干預。

## 腦死（Brain Death）

**Brain death** 是**整個大腦（包括腦幹）所有功能的不可逆停止**。

### 腦死判定檢查清單

**表 45.6｜Brain Death 判定檢查清單**

| 步驟 | 要求 |
|---|---|
| **先決條件** | 已知昏迷原因；排除混淆因素（**低溫**、**藥物中毒**、**嚴重電解質/代謝障礙**） |
| **臨床檢查** | 所有腦幹反射消失（瞳孔、角膜、眼前庭、氣管）；對疼痛刺激**無運動反應**（去大腦/去皮質姿勢可接受） |
| **Apnea Test（呼吸暫停試驗）** | 當 PaCO₂ 升高到閾值（**≥60 mm Hg** 或超過基線 **20 mm Hg**）以上時**沒有呼吸努力** |
| **輔助檢查**（如果臨床檢查無法完成或不可靠） | **EEG**（腦波靜止）、**腦血管造影**（無腦血流）、**核醫學掃描**、**TCD**（無舒張血流） |

### 確認性觀察

- 如果步驟 1–4 已確認，或有陽性的確認性檢查，可以宣布患者**法定死亡**
- 在大多數司法管轄區，一套臨床發現就足夠了
- 如果有任何不確定性，應**重複檢查**

> **法律提醒：** 腦死判定必須符合當地法律和醫療機構的標準程序，通常需要一名以上的資深醫師確認。

## 意識狀態評估流程圖

```
意識障礙患者
    │
    ├─ 可喚醒 ─┬─ 覺知正常 → 焦慮 / 嗜睡（可觀察）
    │          └─ 覺知障礙 → Delirium（CAM-ICU 篩檢）
    │
    └─ 無法喚醒 ─┬─ 有覺知跡象 → 植物人狀態
                 ├─ 無覺知 ─┬─ 可逆 → 昏迷 / 木僵
                             └─ 不可逆 → 腦死
```

---

## 總結：ICU 意識障礙的關鍵要點

| 主題 | 關鍵點 |
|---|---|
| **Delirium** | ICU 常見（尤其是低動型）；CAM-ICU 篩檢；Haloperidol 為一線治療 |
| **GCS** | **GCS ≤8** = 昏迷；同時評估瞳孔和運動反應 |
| **瞳孔異常** | 單側放大固定 = 腦疝；針尖瞳孔 = opioid 過量或橋腦出血 |
| **Alcohol 戒斷** | 72–96 小時達峰；Benzodiazepines + Thiamine 治療 |
| **Brain death** | 不可逆；需排除混淆因素；Apnea test 陽性 |
