## Chapter 24: Acute Respiratory Distress Syndrome

> "Physicians think they do a lot for a patient when they give his disease a name."
> — Immanuel Kant

本章描述的疾病多年來有過多個名稱，包括：休克肺、Da Nang 肺（來自越戰）、僵硬肺、漏毛細血管性肺水腫、非心源性肺水腫、急性肺損傷、成人呼吸窘迫症候群，以及最近的急性呼吸窘迫症候群（ARDS）。然而，這些名稱沒有一個能提供任何關於該疾病的實用資訊。該疾病是一種瀰漫性肺部炎症損傷，是現代急性呼吸衰竭的主要原因之一（1–3）。

## 導讀摘要

- ARDS 為瀰漫性肺炎症性損傷，誘發條件包括肺炎（約 60%）、肺外敗血症（16%）、胃內容物吸入（14%）
- 診斷標準：**PaO₂/FIO₂ ≤300 mm Hg**（with **PEEP** ≥**5 mm Hg**），雙側肺浸潤，7 天內急性發作
- **肺部保護性通氣**為改善預後的唯一策略：tidal volume **6–8 mL/kg** 預測體重，plateau pressure **≤30 cm H₂O**
- 類固醇治療：COVID-19 使用 **dexamethasone** **6 mg** IV/PO daily ×10 天；中重度 ARDS 使用 **methylprednisolone** **1–2 mg/kg**/day
- 俯臥姿勢（prone positioning）可改善中重度 ARDS（**PaO₂**/FIO₂ **<150 mm Hg**）存活率


### 致病機轉

ARDS 的首份臨床報告出現在 1967 年（4），涵蓋了 12 名對治療無反應的低血氧患者，胸部 X 光呈現雙側瀰漫性浸潤。七名患者死亡，屍體解剖發現肺部有發炎滲出液的密集浸潤。沒有感染跡象，表明 ARDS 是一種急性炎症性肺損傷。

#### 炎症性損傷

ARDS 的肺實變始於循環嗜中性球的活化（5）。這導致嗜中性球在肺微循環中滯留，嗜中性球附著於血管內皮並遷移穿過內皮細胞進入肺實質。然後嗜中性球脫顆粒，釋放細胞質顆粒內容物（即蛋白水解酶和毒性氧代謝物）。毛細血管壁後續受損導致含蛋白質液體、紅血球和血小板滲出進入肺部。細胞性和蛋白性滲出液最終充滿並閉塞了末梢空氣腔。發炎滲出液含有纖維素，若發炎在數週內未消退，纖維素可積累並產生不可逆的肺纖維化。

#### 誘發條件

ARDS 不是一種原發性疾病，而是多種感染性和非感染性疾病的後果。容易導致 ARDS 的典型條件列於表 24.1（1）。最常見的原因是肺炎、肺外敗血症、敗血症休克、胃內容物吸入、血液輸注、非心源性休克和多系統創傷（1）。所有這些條件的共同特點是發炎反應中嗜中性球的活化（見圖 17.1），這是 ARDS 的主要誘發事件。大約 10% 的 ARDS 病例沒有可識別的來源（1）。

**表 24.1：ARDS 的誘發條件**

| 感染相關 | 百分比 | 非感染性 | 百分比 |
|---|---|---|---|
| 肺炎 | 60% | 胃內容物吸入 | 14% |
| 肺外敗血症 | 16% | 肺挫傷 | 6% |
| 敗血症休克 | 8% | 血液輸注 | 4% |
|  | | 多系統創傷 | 4% |
| | | 吸入性損傷 | 2% |
| | | 藥物過量 | 2% |

#### COVID-19 與 ARDS

由嚴重急性呼吸道症候群冠狀病毒 2（SARS-CoV-2）引起的肺炎，當導致低血氧性呼吸衰竭時，通常被歸類為 ARDS。在冠狀病毒（COVID-19）大流行的高峰期，住院的 COVID-19 患者中約有三分之一報告出現 ARDS（6）。然而，COVID-19 引起的嚴重低血氧通常與肺順應性（distensibility）的變化很小或沒有變化相關（7），這不是嚴重 ARDS 的典型特徵。因此，COVID-19 代表了一種獨特的 ARDS 類型，這在臨床上很重要，因為許多最近的 ARDS 研究都是在 COVID-19 患者中進行的，結果可能不適用於其他 ARDS 病例。

### 診斷標準

**表 24.2：ARDS 的診斷標準**

| # | Criterion |
|---|---|
| 1 | 急性發作（7 天內） |
| 2 | 胸部 X 光呈現雙側肺泡浸潤 |
| 3 | **PaO₂**/FIO₂ **≤300 mm Hg**，且 **PEEP** ≥**5 mm Hg** |
| 4 | 無左心衰竭或液體過負荷的證據 |
| 5 | 存在誘發條件 |

### 皮質類固醇治療

**表 24.3：ARDS 中皮質類固醇治療的建議**

| 條件 | 藥物療程 |
|---|---|
| **COVID-19（需要 O₂、NIV 或 MV）** | Dexamethasone **6 mg** 靜脈注射或口服每天一次，最多 10 天 |
| **中重度 ARDS（發病 <72 小時）** | Methylprednisolone **1 mg/kg**/天理想體重（IBW）持續輸注；14 天內逐步減量 |
| **中重度 ARDS（7–14 天，持續）** | Methylprednisolone **2 mg/kg**/天 IBW（同樣的逐步減量方案） |

### 俯臥姿勢

俯臥姿勢是 ARDS 中一種重要的治療干預，已被證明可以改善特定患者群體的氧合和存活率。

**表 24.4：ARDS 中的俯臥姿勢**

| 適應症 | 禁忌症 |
|---|---|
| 預防正在自發呼吸、需要高流量鼻 O₂ 或 NIV 的患者插管 | 活動性出血 |
| 促進中重度 ARDS（**PaO₂**/FIO₂ **<150 mm Hg**、FIO₂ **≥60%**、**PEEP** ≥**5 cm H₂O**）機械通氣患者 tidal volume 約 **6 mL/kg** 預測體重（**PBW**）的存活 | 脊柱不穩定 |
| | 多處骨折 |
| | 顱內壓升高（ICP） |
| | 近期氣管切開術或胸骨切開術（2 週內） |

### 肺保護性通氣

肺保護性通氣是唯一在 ARDS 中顯示可改善臨床預後的通氣策略（見第 27 章）。方案摘要如下。

**表 24.5：ARDS 肺保護性通氣方案**

| 階段 | 行動 |
|---|---|
| **第一階段** | 1. 計算預測體重（**PBW**）：男性：**PBW** = 50 + [2.3 ×（身高（英寸）– 60）]；女性：**PBW** = 45.5 + [2.3 ×（身高（英寸）– 60）]。 2. 設定 tidal volume（VT）= **8 mL/kg** **PBW**。 3. 設定 **PEEP** = **5 cm H₂O**。 4. 調整 FIO₂ 以維持 **SpO₂** **88–95%**。 5. 每 2 小時將 VT 降低 **1 mL/kg**，直到 VT = **6 mL/kg**。 |
| **第二階段** | 1. 當 VT = **6 mL/kg** 時，測量 plateau pressure（Pplat）。 2. 若 Pplat >**30 cm H₂O**：將 VT 降低 **1 mL/kg**，直到 Pplat **<30** 或 VT = **4 mL/kg**。 |
| **第三階段** | 1. 監測血氣是否有呼吸性酸中毒。 2. 若 pH 7.15–7.30：增加呼吸頻率（RR）直到 pH **>7.30** 或 RR = **35 breaths/min**。 3. 若 pH **<7.15**：將 RR 增加至 **35 breaths/min**；考慮俯臥姿勢或 ECMO。 |
